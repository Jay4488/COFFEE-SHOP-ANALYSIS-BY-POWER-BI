# COFFEE-SHOP-ANALYSIS-BY-POWER-BI
☕ New Coffee Power BI Dashboard

A professional Power BI dashboard built for a simulated coffee shop business to demonstrate sales, profit, and performance insights. This project showcases data modeling, DAX, Power Query, and interactive report features inspired by an internship-based ML project titled "MovieMate."

📊 Dashboard Features

🔢 Key KPIs: Total Sales, Orders, Profit, Avg. Order Value

🧭 Slicers: Date, Category, Region, Branch

📆 Time Series: Monthly/Weekly performance trends

🍩 Donut Charts: Category-wise product sales

🏬 Branch Analysis: Compare performance across different locations

📈 Interactive Visuals: Drillthrough, cross-filtering, tooltips

🛠️ Tools & Technologies

Power BI Desktop

DAX (Data Analysis Expressions)

Power Query for ETL (Extract, Transform, Load)

Excel/CSV for data input
